# ГИБДД-Очевидец

Android-приложение очевидца для анонимной отправки сообщений сотрудникам ГИБДД. Репозиторий содержит только клиент роли **Очевидец**; приложение сотрудника разрабатывается отдельно.

## Стек

- Kotlin, Jetpack Compose, Material 3;
- Navigation Compose;
- Retrofit, OkHttp, Gson;
- Room для локального кэша подтверждённой истории;
- Yandex MapKit;
- Coil для фото и GIF;
- Media3 ExoPlayer для видео;
- Android Keystore для защищённого хранения сессии;
- minSdk 26 (Android 8.0).

## Реализовано

- приветственный экран только при первом запуске и единый непрерывный чат;
- автоматическая повторная регистрация и обновление токена при следующих запусках;
- анонимная регистрация устройства по SHA-256 fingerprint;
- повторная регистрация с сохранением `device_id` и обновлением `access_token`;
- защищённое хранение `device_id` и токена через Android Keystore;
- отправка и получение текстовых сообщений;
- мгновенное отображение локальной истории из Room с последующей синхронизацией через REST/WebSocket;
- загрузка фото, видео и GIF с ограничениями размера из ТЗ;
- выбор медиа через Photo Picker, пять последних фотографий и съёмка камерой;
- восстановление медиа из истории после перезапуска приложения;
- полноэкранный просмотр фото/GIF и воспроизведение видео;
- отправка текущего местоположения;
- выбор статической точки на Яндекс Картах и поиск адреса;
- live-геолокация на 15 минут с отправкой точки каждую секунду и досрочной остановкой;
- группировка сообщений по дням и отображение локального времени;
- статусы для текста, медиа и статической точки: одна галочка — сервер принял сообщение, две — заполнено `delivered_at`;
- синхронизация истории сразу после отправки текста, медиа и статической точки без ожидания следующего polling;
- получение событий новых сообщений и доставки через WebSocket;
- автоматическое переподключение WebSocket с REST-синхронизацией;
- индикатор состояния WebSocket: подключение, онлайн и отсутствие соединения;
- зашифрованная локальная очередь текста, статической геолокации и метаданных медиа с повторами в течение минуты;
- приватные локальные копии неотправленных фото и видео, восстановление очереди после перезапуска и ручной повтор;
- резервный polling истории при недоступном WebSocket;
- проверка активного бана и отдельный экран временной/постоянной блокировки;
- реакция на бан через WebSocket и остановка активной live-геолокации;
- клиентская поддержка Firebase Cloud Messaging, синхронизация Firebase Installation ID через `push_token` и системные уведомления;
- foreground-service и уведомление во время live-геолокации.

## Firebase Cloud Messaging

Клиентская часть FCM подключается автоматически, когда в каталог `app/` добавлен файл `google-services.json` для Android-приложения с package name `com.example.skbt_up_gibdd_eyewitness`. Без этого файла Firebase отключён, а обычная debug-сборка продолжает работать.

После добавления файла приложение регистрируется в FCM, передаёт Firebase Installation ID backend в поле `push_token`, обновляет его при повторной регистрации и показывает уведомления о новых сообщениях. Для Android 13 и новее приложение запрашивает разрешение на уведомления при открытии чата.

## Backend

Публичный тестовый API по умолчанию работает по HTTPS:

```text
https://xn--e1afhclgq.xn--p1ai:4401/
```

Это punycode-запись адреса `https://силенок.рф:4401/`, которая надёжно обрабатывается Retrofit и Gradle. Сервер использует доверенный сертификат Let's Encrypt, поэтому отдельная настройка сертификата и разрешение cleartext traffic не нужны.

Другой HTTPS-адрес можно передать через Gradle property; URL должен оканчиваться `/`:

```powershell
.\gradlew.bat :app:assembleDebug -PAPI_BASE_URL=https://server.example.ru/
```

Клиент использует заголовки:

```http
X-Client-App: eyewitness
Authorization: Bearer <access_token>
```

Подключены регистрация, история чата, текст, статическая и live-геолокация, загрузка/скачивание медиа и `delivered_at`. Медиа хранится на backend семь дней с момента последнего скачивания.

## Настройка Яндекс Карт

Добавьте ключ MapKit только в локальный `local.properties`:

```properties
MAPKIT_API_KEY=your_mapkit_key
```

`local.properties` исключён из Git и не должен попадать в коммит.

## Запуск

1. Открыть корень репозитория в Android Studio.
2. Добавить `MAPKIT_API_KEY` в `local.properties`.
3. Дождаться Gradle Sync.
4. Запустить конфигурацию `app` на устройстве или эмуляторе с Android 8.0+.

Сборка из PowerShell:

```powershell
.\gradlew.bat :app:assembleDebug
```

Debug APK создаётся в `app/build/outputs/apk/debug/app-debug.apk`.

UI-тесты ключевых экранов запускаются на подключённом эмуляторе:

```powershell
.\gradlew.bat :app:connectedDebugAndroidTest
```

## Структура

- `core/network` — Retrofit API и авторизационные заголовки;
- `core/storage` — защищённая сессия устройства;
- `data` — реализации репозиториев;
- `domain` — модели и интерфейсы репозиториев;
- `feature/chat` — чат, вложения и отображение сообщений;
- `feature/location` — карта, статическая и live-геолокация;
- `ui` — тема и общие Compose-компоненты.

## Ещё не реализовано

- Для сквозной проверки push-уведомлений нужен `app/google-services.json` от общего Firebase-проекта и отправка уведомлений со стороны backend.
- При сохранённой сессии offline-запуск пока блокируется повторной регистрацией устройства; для полноценного offline-режима требуется открывать Room-кэш до ответа backend.

Эти возможности требуют следующих backend-контрактов или отдельного этапа реализации.
